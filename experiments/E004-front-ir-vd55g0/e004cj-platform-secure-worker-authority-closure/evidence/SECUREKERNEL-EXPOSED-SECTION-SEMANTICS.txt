STATIC INTERPRETATION
- GetExposedSecureSection is not a VTL0 exposure API.
- Secure Kernel maps the transfer descriptor, creates a secure-section object,
  allocates secure PTE storage, claims each supplied physical page with
  SkmiClaimPhysicalPage(), and writes Secure Kernel PTEs.
- The xHCI SecureCompanion then uses that secure-section handle as input to
  DmaMapMemory for the controller.
- Therefore "exposed" means externally described pages admitted/claimed into
  a Secure Kernel secure object, not protected pages exposed to ordinary HLOS.
