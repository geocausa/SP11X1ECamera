`bhist-request.h` takes a caller-owned AEC rectangle, active crop and request ID. It rejects a missing config, out-of-crop geometry, a count that would truncate the Titan680 field, a reused state or wrong request ID. Preparation writes its isolated state only after E006u has generated the word; consumption is one-shot. This detached header is not wired into CAMSS or hardware.
