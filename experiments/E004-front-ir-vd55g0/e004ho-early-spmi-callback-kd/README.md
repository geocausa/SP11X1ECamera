**It hit naturally at uptime 16.243 seconds.** Original KD captured x2=0x00019246, x4=1 and LR=fffff8035eb63bec. Relative to the observed live PMIC module base, that return address is original PMIC RVA **0x23bec**, immediately after the original indirect call at **+0x23be8**. The original PMIC callsite, disassembled in the same live kernel and independently checked against original SHA-pinned OEM ARM64 bytes, constructs a one-byte masked value, stores it to the temporary input byte, sets the SPMI operation argument w1 to zero and invokes its interface callback. **This is a true natural early SOFTWARE callback-entry positive control for the PMIC masked one-byte write path.** The operation argument was inferred from the original live callsite; w1 itself was **not** recorded at the callback entry. The payload pointer, payload value and any private data were NOT logged.

Decoding the **captured SOFTWARE selector word** by the original format gives bus nibble 0, SID nibble 1, 16-bit register start **0x9246**, one byte long. This request does **not** intersect the flash timer-address range 0xee3e..0xee41. The actual downstream SPMI MMIO command/status, successful silicon write, or PMIC flash timer configuration were NOT observed here. It does not identify the first origin of the previously archived four idle 0x93 timer bytes. A bus software request is not proof that a physical IR emitter was enabled, its optical current or pulse width, or an autonomous stuck-trigger/host-crash cutoff.
