# E004ha — original OEM generic PMIC write callback and descriptor producers

**Offline PASS, 2026-09-20.** Continuing E004gz, the original SHA-pinned Windows ARM64 `qcpmic8380.sys` exposes the still address-capable generic raw-write wrapper (RVA `0x32b70`) in its genuine runtime callback table at `.data` RVA `0x3a510`. This new audit traces how the callback table address is published rather than misidentifying CFG/unwind metadata as callers.

The original four consecutive 64-bit callbacks at RVA `0x3a4f8` point to code RVAs `0x327c0`, `0x32920`, `0x329e0`, and **`0x32b70`**. The descriptor-construction routine at code RVA `0x2f918`, directly called at RVA `0x20304`, forms `0x3a4f8` and writes that pointer into a descriptor. A separate routine at code RVA `0x2fdd0`, directly called at RVA `0x2021c`, checks an input structure field against `0x4a` and, on the relevant path, stores the pointer **`0x3a508`** into another descriptor. Thus the generic writer appears at index three of the four-function table and at index one of the two-function suffix. We have **not** identified what the input `0x4a` signifies, nor proved this specific interface was called by Windows during IR preview.

The writer's original code at RVA `0x32b70` accepts a 16-bit register address in `w1`, an 8-bit length in `w2` and buffer pointer in `x3`, then calls the raw-write helper at RVA `0x23dc8` through a direct original ARM64 call at `0x32c2c`. No direct ARM64 `bl` to the wrapper was found in the scanned executable sections; the table is an actual runtime callback pointer, **not** an observed runtime invocation. This strengthens the reason to debug the callback entry and descriptor-construction callers as a distinct path, rather than repeating the selected masked-helper breakpoint used in E004gx.

Reproduce entirely offline with `python3 experiments/E004-front-ir-vd55g0/e004ha-generic-pmic-callback-registration/verify_static.py` and `python3 experiments/E004-front-ir-vd55g0/e004ha-generic-pmic-callback-registration/test_static.py`. The original PE hash and exact callback pointers, registration-site instructions, wrapper argument transforms and raw-helper call are pinned; twelve negative instruction cases PASS. The original `0x93` timer-register writer, whether or when this callback actually runs, PMIC fault behavior and physical illumination remain **unknown**. No Windows/KD/camera/PMIC/LED experiment was performed in this stage; SP11 remains Golden Linux, Linux emitter/login unchanged.
