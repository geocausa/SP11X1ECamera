## Actual source integration and finite scope

A new isolated copy of accepted CAMSS adds the same reviewed header `camss-e004pz-front-owner-observer.inc` to copied `camss.h`, and a per-device, spinlocked `e004pz_front_observer` to the copied `struct camss`. It initializes the sidecar **ONCE at device allocation** before the existing IRQ registration; the accepted driver and Golden are unchanged. The exact custom front runner `camss_x1e_pix_runner_frames`, not generic VFE1 PIX v2 (which is deliberately denied on X1E), acquires a strictly increasing front-runner owner epoch **after its existing exact front sensor/PHY/format/media-link graph validation and capsule preparation, but BEFORE existing pipeline power, VFE/CSID start or RT-CDM submission**. The same runner releases its scope only on the pre-existing safe full teardown, and pins the sidecar indefinitely if the pre-existing hardware stop fails and keeps DMA/power allocated until reboot. The C11 model checks normal and unsafe stop and late-generation rejection.

The copied CSID1 ISR reads/acknowledges the hardware status **exactly once using existing unchanged instructions**, then adds one non-retiring software call consuming the same already-latched `buf_done_val`. Only non-lite X1E CSID1 with CSID PHY/format presently matching the existing exact front route predicate is considered front-scoped *and only while the custom front runner's owner epoch is active*. Bit7 with no current front route/runner is **UNATTRIBUTED**, never relabelled rear. A bit7 event with a current front route is counted as a **front-runner-scoped STATUS OBSERVATION**, not hardware WM16 completion. The internal per-session/lifetime counters and last front-scoped status are not exposed through a user-facing diagnostic yet. No extra MMIO read/IRQ ACK, IOMMU/DMA operation, `camss_buf_done`, VFE/PIX/RDI/VB2 buffer return, BF FIFO8 dequeuing or rear processing change was added.

**Important safety limit:** The existing custom front runner's validated graph is NOT an independently complete global front/rear VFE1 exclusion gate. Other userspace media/V4L2 paths, graph relinking and rear software/RAW paths are not shown to acquire this sidecar; this code cannot authorize a rear owner or prove that any source's physical mode stayed immutable at every interrupt. A current PHY+format check is a configuration check, not a hardware-attested sensor identity, and a C11 test's synthetic bit7 is not a live IRQ. No real same-generation BF/FIFO8 entry, nonnull outstanding WM16 identity/tag or independent exact-buffer IRQ/ACK/DMA/IOMMU-safe stop source has been implemented. Native rear processed ISP authorization always returns `-EOPNOTSUPP`.
