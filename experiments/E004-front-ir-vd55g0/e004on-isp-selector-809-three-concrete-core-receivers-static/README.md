CDM's nonzero default return does not prove that a live 0x809 caller selected CDM; it could choose a different list, skip disabled records or execute an alternate interface. The exact selected Windows rear VideoRecord profile and full 0x809 argument/return ABI of *other* possible first-callback records remain unproven.
