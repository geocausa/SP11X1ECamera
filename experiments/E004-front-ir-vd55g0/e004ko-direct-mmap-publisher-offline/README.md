# E004ko direct rear publisher
Camera-free source and fake-device tests for a bounded native rear RAW10 mmap capture → unchanged accepted Bayer conversion → direct standard V4L2 NV12 write publisher. Removes RAW/NV12 pipes and the separate GStreamer publisher. This still copies NV12 into loopback; it is not zero-copy ISP.
The exact accepted scalar converter is included from E004kk. Live operation fails closed outside the fresh E004kp boot token and root. It accepts only qcom-camss SGRBG10P4076x2806 single-plane multiplanar capture with exact stride/bytes, and /dev/video90 v4l2loopback SP11-Rear-Preview output. It never configures graph links, sensor registers, boot or modules.
Bounds: at most2400frames,210seconds,4capturebuffers,1NV12buffer; SIGTERM/SIGINT stop, STREAMOFF, unmap and close. The candidate service adds an external timeout and Golden return.
Seven fake-device cases cover success, wrong source format, short payload, flagged corrupt buffer, short publication, poll failure and termination. Tests also check token boundaries, reject the consumed E004km token, and verify no live execution on Golden. Fake devices do not establish actual ioctl/runtime compatibility or throughput; those require a new one-shot.
