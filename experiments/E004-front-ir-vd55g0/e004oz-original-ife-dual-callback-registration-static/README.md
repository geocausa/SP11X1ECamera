This bounds the question more precisely than merely finding a compatible status-record layout: **the snapshot callback is registered and callable through the original ISP's exposed wrapper, but the original source examined so far does not establish its invoker or the type-1 event-record producer that binds the snapshot buffer to an event and frame**. Searching only for a direct function call would be insufficient because the registration is via function pointers. The separate type-2 callback's known producer-to-worker chain must not be silently reused as the missing type-1 chain.
